## cms-vue3：技术收口（联动状态隔离 + CMS 单测基线）

### 结果
两个 commit：`34279ba`（引擎隔离）、`a3e12c2`（测试基线清理）。

### 一、联动引擎状态隔离
引擎原实现把传入对象原样存 Map 且直接改 `enabled`（上面那条踩坑 #1 的根因）——store 因注册前浅拷贝恰好掩盖，但引擎 API 契约不安全。修复：注册存浅拷贝、setLinkageEnabled 副本替换、get* 返回拷贝（CMS/CRS 同步）。**注意 `{...linkage}` 浅拷贝即可**：transformFn/condition 只读，深拷贝反而会丢函数。

同期移除 keyword（无消费方）：`runtimeEventProperties` 只剩 `filteredCount`、RenderNode 删 keyword 桥接、`filter-change` payload 收敛为 `{ filteredCount }`。

### 二、CMS 单测基线
**24 文件 / 33 条失败 → 0 失败 / 0 错误**。拆解：17 个文件是 Playwright spec 被 Vitest 误收集（`**/*.spec.ts` 匹配到 `tests/e2e*`）；7 个文件 33 条是真契约漂移（condition-engine 18 / data-binding 3 / page-publish 3 / LinkageConfig 5 / generate-material 2 / performance 1 / linkage 1）。

### 踩坑（重要，可复用）
1. **Vitest forks 池在本机会随机 EPERM + 静默跳过整个测试文件**（不报失败！）——实测三次中两次各丢一个文件（usePageStore 59 条 / condition-engine 31 条），并行跑出的测试总数每次不同。根因：worker 间经临时文件（`%TEMP%\...\web\<hash>`）传递模块被 fs 层拦截。**修复：显式 `pool: "threads"`**。效果：7.8s 稳定全绿（forks 9.5s 不稳，`--no-file-parallelism` 57s）。CMS 与 ui 两个 vitest.config 都已加。
2. **判断"并行跑绿"要先核对测试总数**——丢文件时 vitest 不报失败，靠总数/文件数比对才能发现。
3. condition-engine 的 field 支持两种写法了：显式路径 `componentState.x` + 裸名（componentState → pageState → userData 回退）。
4. page-publish 测试此前完全基于已删除的 localStorage 架构，重写为 mock `@/api/activity` 的服务端契约测试。

## cms-vue3：装修页三栏布局修复 + 五链路浏览器全量演示

### 布局修复（commit `d22664c`）
装修页三栏是「浮层拼贴」：TopHeader `position: fixed`、左右面板 `position: absolute` 均不占流，画布按整页宽度布局 → 四处问题：
1. 画布顶部「页面画布」标题被固定工具栏压掉一半 → `.decorate-content` 加 `margin-top: 56px`
2. **画布组件横向铺进左栏、右栏裁掉组件右端**（列表「处理中」显示成「处理」）→ `.canvas-area` 加 `margin-left: 186px; margin-right: 376px`
3. 左栏搜索框 placeholder 截断 → 改「搜索物料」
4. 组件排序手柄「拖」超出画布左缘 8px 被裁半 → `left: -32px → -24px`

方案：`absolute + 预留空间`（非 flex 三栏）。`decorate-content` 建 `position: relative` 定位上下文，面板改 `top: 0`（相对 content）+ `z-index: 20`。
**验证**：1440 三栏 rect = `186|878|376`；命中测试三点各归其位；无横向滚动；拖拽 2→3；mock E2E 32/32。

### 五链路演示（真实浏览器 + dev 库，全通）
- 环境修复：**dev 库落后 4 个迁移**（pages 缺 review_note 等列 → 页面列表/AI 建页 500）→ `migration:run`；旧模板 10 套无 business → 清 templates + `seed`（13 套）
- 链路一 AI 建页：AI(数据查询) → 生成 → 审核 → 发布 → CRS 正式页真实渲染（20.7s）
- 链路二 表单：模板建页 → 提交 → **线索入库（备注含 JSON「预约日期」）**（16.4s）
- 链路三 联动：搜索「资料」→ 列表 2 行 + 统计卡 2（19.3s）
- 补充 回滚：二次发布 v2 → 发布记录 → 回滚 v1 → CRS 验证（17.4s）
