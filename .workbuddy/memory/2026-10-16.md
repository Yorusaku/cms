2. **CRS 此前没有单测基建**——而联动逻辑恰在 CRS 侧。补了最小 vitest 配置（读 workspace 源码 + jsdom），不接 Vant resolver（当前测纯逻辑）。

4. **Docker Desktop 没运行时 live E2E 直接起不来**（webServer 连不上 5433）；`Start-Process` 拉起后它可能自杀一次，需要再拉一次（看到 `com.docker.backend` 进程才算成功），容器会自动恢复。
